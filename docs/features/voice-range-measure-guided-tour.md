# 음역 측정 가이드드 투어 + 한국어 친화 표기 통합 (F1)

> 본 spec 은 `user-persona-and-pain-points.md` §5 F1 에서 분기된 **자식 spec stub** 이다. 본격 작성 (§5/§6/§7 세부) 은 다음 plan 사이클에서 확장한다. 본 stub 은 합의 골격과 비범위를 둔다.

## 1) 개요 (What / Why)

- 페르소나 C (음역 입문자) 의 첫 진입 이탈 (#318 회상 — "D3 가 뭔지 모름") 및 페르소나 A·B 의 측정 신뢰도 부재 (P4) 를 해결.
- 첫 측정 화면을 **가이드드 투어** + **한국어 병기** + **측정 신뢰도 표시** 3 요소로 옷 입혀, 측정 첫 5분 안에 사용자가 자기 음역을 의미 있게 이해한다.

## 2) 사용자 시나리오

1. 첫 진입 사용자가 "음역 측정 시작" 클릭 → 가이드드 투어 step 1 (자세) / step 2 (마이크 거리) / step 3 (최저음 측정) / step 4 (최고음 측정) / step 5 (결과 + 한국어 병기 + 신뢰도) 순으로 안내.
2. 결과 화면에서 `D3 (레3, 중간 도 아래)` + 측정 신뢰도 ("3회 평균 분산 ±2 semitone") 표시.
3. 재측정 권장 조건 (분산 큼) 시 한 줄 가이드 + 재측정 CTA.

## 3) 요구사항

### 기능 요구사항
- [ ] 가이드드 투어 5 step (자세 / 마이크 / 최저음 / 최고음 / 결과)
- [ ] 한국어 음명 병기 — 모든 음역 표시 라벨 (`D3 (레3)` 또는 `레3 (D3)`)
- [ ] 옥타브 위치 한 줄 안내 (`중간 도 아래`, `중간 도`, `높은 미` 등)
- [ ] n회 측정 (기본 3회) 자동 권장 + 측정값 평균 + 분산 표시
- [ ] 분산 임계치 초과 시 재측정 권장 메시지

### 비기능 요구사항
- 가이드드 투어 lib 도입 시 ADR 작성 (Q1 — 비범위 의사결정)
- 측정 1회 ≤ 30 초, 가이드드 투어 전체 ≤ 5 분 (P95)
