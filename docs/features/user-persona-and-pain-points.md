# 사용자 페르소나 + 페인 포인트 + 신규 feature 우선순위

## 1) 개요 (What / Why)

본 spec 은 mobruji 가 "기능적으로는 작동하지만 실사용자에게 와닿지 않는다" 는 사용자 진단 (2026-05-24) 을 출발점으로, 페르소나와 페인 포인트를 정의하고 신규 feature spec 의 우선순위를 정렬하는 **상위 합의 문서** 다. 개별 feature 의 구현 계획은 본 spec 에서 파생된 자식 spec (`high-note-training-mode.md`, `voice-range-measure-guided-tour.md`, `mood-mode.md` 등) 에서 다룬다.

### 1-1) 배경 (사용자 인용)

> "지금의 서비스가 나는 정말 좋은 아이디어라고 생각하는데, 아직도 실제 사용자가 편리하게 이용하기에는 거리가 먼 거 같아. 음역대 설정도 실용적이지 않은 거 같고 (D3? 이게 무슨 뜻이지? 내 음역대의 최저음은 뭐지? 잘 모르겠어). 좀 더 실질적으로 도움이 될 수 있는 기능들이 필요해 (나는 노래 연습을 하고 싶어. 발성 연습에 좋은 노래! 고음 뚫는 노래! / 나는 분위기를 띄우는 노래가 필요해). 기획자의 입장에서, 사용자 페인 포인트와 페르소나를 정의하고 그에 맞추어서 후속 작업을 기획하도록 작업을 지시해줘."
> — 2026-05-24

### 1-2) 직전 closed 회고

이전 사이클에서 사용자 직접 피드백 기반으로 close 된 이슈는 본 spec 의 출발 신호다.

| 이슈 | 핵심 발견 | 본 spec 과의 관계 |
|---|---|---|
| #318 | "D3 E2 이런 게 뭔지 모를 수도 있을 거 같아" — 음역 표기 직관성 부족 | 페인 P1, 페르소나 C 의 핵심 진입 장벽 |
| #136 | 외부 ref (Vanido, Yousician, Spotify) 영감 부족 | 페르소나·페인 정의의 입력. F1/F2 의 ref 출처 |
| #320 | "추천 끝났네, 다음은?" — empty CTA 부재 | 페인 P5. 페르소나 A·B 모두 hit |

3건 모두 "기능은 작동하나 사용자에게 의미 있는 다음 액션을 못 준다" 는 동일 구조의 결함을 보여 준다. 본 spec 은 이 패턴을 **페르소나별로 의미 있는 한 줄** 로 다시 묶어 후속 feature 의 가치를 명확화한다.

## 2) 페르소나

5 종을 정의한다. A·B·C 는 v0.3 우선 타깃, D·E 는 v0.4+ 검토 후보.

### A. 연습러 — "프로처럼 부르고 싶다"

| 항목 | 내용 |
|---|---|
| 인구통계 | 20-35세, 남녀 무관, 노래방 주 2-3회 또는 보컬 학원 병행 |
| 노래방 빈도 | 주 2회+ (코인 노래방 위주 단독 방문 포함) |
| 핵심 motivation | 발성·고음·호흡 등 보컬 스킬 트레이닝. 측정 가능한 성장 |
| pain points | (1) 어떤 곡이 발성 연습에 좋은지 모름 (2) 고음 뚫는 곡 큐레이션 부재 (3) 같은 곡 반복 → 정체 |
| 기대 feature | 고음 뚫기 모드, 발성 연습 코스, 진도 트래커, 비포·애프터 측정 비교 |
| 현재 mobruji 만족도 | 낮음 — 분위기/음역 기반 한 줄 추천만 받고 끝남 |

### B. 분위기 메이커 — "이 자리를 살리고 싶다"

| 항목 | 내용 |
|---|---|
| 인구통계 | 25-45세, 회식·동호회·결혼식 사회 등 사회적 자리 빈도 높음 |
| 노래방 빈도 | 월 2-4회, 대부분 다수 동행 |
| 핵심 motivation | 청중 반응 극대화. "분위기 살린 사람" 포지셔닝 |
| pain points | (1) 신나는 곡인지 분위기에 맞는지 판단 기준 없음 (2) 청중 연령대별 다른 선곡 가이드 부재 (3) 본인 음역과 분위기 충돌 시 타협 기준 부재 |
| 기대 feature | 분위기 모드 (신남/감성/뗴창/도입), 청중 프로필 입력, 분위기별 무대 활용 팁 |
| 현재 mobruji 만족도 | 중간 — mood 입력은 있으나 "분위기 메이커" 가치로 옷 입혀지지 않음 |

### C. 음역대 입문자 — "내 목소리를 모른다"

| 항목 | 내용 |
|---|---|
| 인구통계 | 전 연령. 노래방 입문 또는 "내 음역이 어떤지 한 번도 정확히 모름" 군 |
| 노래방 빈도 | 월 1-2회 또는 부정기 |
| 핵심 motivation | 자기 목소리 이해. 추천을 받기 위한 "최소 입력" 부담 최소화 |
| pain points | (1) "D3? 그게 뭔데?" — SPN 표기 진입 장벽 (#318) (2) 측정 가이드 부족 — 어디서 어떻게 입을 벌리고 부르는지 (3) 측정값 신뢰도 모름 (한 번 측정이 진짜 내 음역인가) |
| 기대 feature | 한국어 병기 + 시각화 (#318 후속), 측정 가이드드 투어, 측정 신뢰도 표시 |
| 현재 mobruji 만족도 | 매우 낮음 — 첫 진입에서 "D3 ?" 충격으로 이탈 |

### D. 솔로 가창력 자랑러 (v0.4+ 검토)

| 항목 | 내용 |
|---|---|
| 인구통계 | 20-30대, 1인 코인 노래방 위주, SNS 클립 업로드 친화 |
| 핵심 motivation | "킬링 파트" 자랑. 음역대 한계 곡 도전 |
| pain points | (1) "내 한계 + 1키" 도전 곡 큐레이션 부재 (2) 잘 부른 후 공유/저장 액션 부재 |
| 기대 feature | 도전 모드, 클립 공유, 도전 성공 기록 |

### E. 함께 부르기 듀엣러 (v0.4+ 검토)

| 항목 | 내용 |
|---|---|
| 인구통계 | 연인·친구·가족 동반 |
| 핵심 motivation | 동행과 음역 호환되는 듀엣 곡 찾기 |
| pain points | (1) 두 사람 음역 동시 입력 UX 부재 (2) 듀엣 곡 풀 미분류 |
| 기대 feature | 다중 음역 입력, 듀엣 곡 필터, 파트 분담 표시 |

### 4-1) 매핑 해석

- **P1 (D3?) + P4 (측정 가이드) 각 9점** — 입문자 진입 장벽이자 모든 페르소나에 깔린 베이스. 해결 안 되면 다른 페인 해결도 표면화 어려움.
- **P2 (고음) 8점** — 페르소나 A·D 의 핵심 차별화 기회. 외부 (Vanido) ref 강함.
- **P5 (추천 소진) 7점 / P7 (explain) 7점 / P10 (소셜) 7점** — 중간 그룹. P5 는 #320 단기 완화 후 페르소나별 진로 부재가 잔존. P7 은 #136 영감 기반 장기.
- **P3 (분위기) 6점** — 페르소나 B 단독 강하지만 v0.3 차별화 가치 큼.
- 하위 (P6/P8/P9) — v0.4+ 로 미룬다.
