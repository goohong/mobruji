## 1. 처리 목적

본 서비스는 다음 목적으로 개인정보 (또는 결합 시 개인정보가 될 수 있는 정보) 를 처리합니다.

| 목적 | 처리 항목 |
|---|---|
| 곡 추천 제공 | 음역대 (`lowMidi`/`highMidi`), 분위기 / 연령대 / 선호 BPM 옵션, 추천 history |
| 사용자 단위 상태 보관 (익명) | sessionId, 좋아요 (songId 목록), 북마크 (songId 목록), 음역 스냅샷 시계열 |
| 음역 측정 (마이크 실측 옵션) | 마이크 audio (브라우저 메모리 안 일시 처리) |
| v0.4 회원 관리 | 이메일 / OAuth 식별자, 비밀번호 해시 (이메일 가입 시), 프로필 (선호 장르 / 분위기 / 성별 nullable) |
| 서비스 운영 / 통계 / 보안 | IP, User-Agent, access log, 쿠키 |
| 정보주체 권리 행사 응답 | 위 항목 중 본인 확인에 필요한 최소 항목 |

## 2. 처리 항목

### 2-1) 익명 이용 단계 (v0.2 - v0.3)

- 자동 수집: sessionId (UUID v4), IP, User-Agent, 쿠키, access log
- 사용자 입력: 음역대, 분위기 / 연령대 / 선호 BPM, 좋아요 / 북마크
- 옵션 수집: 마이크 audio (음역 측정 마이크 실측 선택 시) — **브라우저 메모리 안만 처리, 서버 미전송**

### 2-2) 회원 이용 단계 (v0.4 이후)

- 위 익명 단계 항목 +
- 회원 식별: 이메일 (이메일 가입) 또는 OAuth 식별자 (`provider`, `providerUserId`) — 카카오 / 구글
- 비밀번호 해시 (이메일 가입 시, 단방향 해시)
- 프로필: 선호 장르 (다중) / 선호 분위기 (다중) / 기본 성별 (선택 / nullable)
- 익명 → 회원 머지 시: 익명 sessionId 누적 데이터 (좋아요 / 북마크 / 음역대) 의 회원 계정 owner 치환

## 3. 처리·보유 기간

| 항목 | 보유 기간 |
|---|---|
| sessionId + sessionId 연결 비식별 데이터 (음역대 / 좋아요 / 북마크 / 추천 history) | 최초 발급 또는 최근 활동일로부터 **180일** 후 자동 만료 (`docs/decisions/0013-sessionid-ttl-rotation.md`) |
| 회원 (이메일 / OAuth) 식별 정보 + 프로필 | 회원 탈퇴 또는 가입 후 **1년간 미접속** 시 파기 (장기 미사용자 처리 — 별도 정책 정합) |
| access log (IP / User-Agent / endpoint) | 통신비밀보호법 등 관련 법령 보존 기간 안 (정식 게시 시 명시) |
| 비밀번호 해시 | 회원 탈퇴 시 즉시 파기 |
| 마이크 audio (옵션) | **0 (보관 X)** — 브라우저 메모리 안 분석 후 즉시 폐기 |
| 정보주체 권리 행사 기록 | 처리 완료 후 3년 (개인정보보호법 시행령 권고) |

## 4. 제 3자 제공

본 서비스는 사용자의 별도 동의 또는 법령에 따른 의무 외에는 **개인정보를 제 3자에게 제공하지 않습니다**.

다음 경우는 예외입니다.

- 법령에 따른 수사기관 등의 적법한 요청
- 사용자가 명시적으로 동의한 외부 서비스 연동

## 5. 처리위탁

| 수탁자 (예시 — 정식 게시 시 확정) | 위탁 업무 | 위탁 항목 |
|---|---|---|
| 클라우드 호스팅 사업자 (예: NCP / AWS / GCP) | 인프라 호스팅 / DB | 본 서비스 처리 항목 전체 (저장·전송) |
| YouTube (Google) | 외부 영상 embed 표시 | IP / 쿠키 (Google 정책 별도 적용) |
| MusicBrainz / Cover Art Archive | 곡 메타·앨범 커버 URL 조회 | 사용자 식별 정보 미전송 (서버→외부 read-only) |
| 카카오 / 구글 OAuth (v0.4) | 회원 인증 | 인증 토큰 교환 (사용자 식별자) |

> 모든 수탁자와의 위탁 계약은 개인정보보호법 제26조에 따라 위탁 사실 / 항목 / 기간 / 안전성 확보 조치를 서면 약정합니다 (정식 게시 시 의무).

## 6. 국외이전

- 위 §5 수탁자 중 일부 (예: Google YouTube embed, OAuth) 는 국외 서비스 사업자입니다.
- 국외이전 항목 / 이전 받는 자 / 이전 국가 / 이전 시점 / 이전 방법 / 이용 목적 / 보유 기간은 **정식 게시 시 명시** (개인정보보호법 제28조의8).
- 사용자는 국외이전에 동의하지 않을 권리가 있으며, 동의 거부 시 일부 기능 (외부 embed / OAuth 로그인 등) 이용이 제한될 수 있습니다.

## 7. 정보주체 권리 (열람 / 정정 / 삭제 / 처리정지)

사용자는 본인의 개인정보에 대해 다음 권리를 행사할 수 있습니다.

| 권리 | 익명 단계 행사 채널 | 회원 단계 행사 채널 |
|---|---|---|
| 열람 | (해당 sessionId 의 클라이언트 localStorage / 서버 read endpoint) | "내 정보" UI |
| 정정 | 음역 재측정 / 좋아요·북마크 토글 | 프로필 수정 |
| 삭제 | `POST /api/v1/sessions/rotate` (sessionId 회전 → 기존 데이터 owner 단절) + sessionId 삭제 endpoint | 회원 탈퇴 endpoint |
| 처리정지 | sessionId 회전 + 본 서비스 미사용 | 회원 탈퇴 + 별도 요청 |

법정대리인 (만 14세 미만 보호자) 도 동일한 권리를 행사할 수 있습니다.

## 9. 자동수집장치 (쿠키) 운영·거부

본 서비스는 다음 목적으로 쿠키를 사용할 수 있습니다.

- 세션 유지 / 사용자 단위 상태 보관 (sessionId 관련)
- 로그인 유지 (v0.4 회원 단계)
- 서비스 이용 통계 / 오류 디버깅

사용자는 브라우저 설정에서 쿠키 저장을 거부할 수 있으며, 거부 시 일부 기능 (sessionId 단위 좋아요 / 추천 history 등) 이용이 제한될 수 있습니다.

## 12. 본 서비스 특화 처리 (음역대 / 마이크 audio / sessionId)

본 항목은 표준 양식에 포함되지 않은 본 서비스 고유 처리에 대한 사용자 고지입니다.

### 12-1) 음역대 데이터

- 음역대 (`lowMidi` / `highMidi`) 는 MIDI note number 정수 2개로 표현되는 **비식별 음역 측정값** 입니다 (사용자 식별 정보 부재).
- sessionId 와 결합 시 비식별 → 결합정보 회색지대 (`license-privacy-risk-audit.md §3-1`) — 본 서비스는 결합 risk 를 인지하고 sessionId TTL (180일) + access log 보존 기간 단축으로 risk 를 완화합니다.
- 음역 스냅샷 (`VoiceRangeSnapshot`) 은 사용자의 음역 발전 인지를 위해 시계열 보관됩니다. 추천 결정성에는 영향 없습니다.

### 12-2) 마이크 audio (음역 측정 마이크 실측 옵션)

- 마이크 audio 는 **브라우저 메모리 안에서만 처리** 되며 **서버로 전송되지 않습니다** (현 spec 정책).
- 분석 완료 시 즉시 폐기되며 보관 매체 (로컬 스토리지 / 서버 / 외부 출처) 어디에도 저장되지 않습니다.
- 마이크 권한 부여는 사용자의 명시적 동의 (브라우저 `getUserMedia` 권한 다이얼로그) 를 통해서만 이루어집니다.
- 향후 서버 분석 도입 검토 시 별도 동의 절차 + 본 항 개정 의무 (`license-privacy-risk-audit.md §10 Q3`).

### 12-3) sessionId

- sessionId 는 본 서비스가 익명 사용자를 식별하기 위해 발급하는 **무작위 UUID v4** 입니다. 사용자의 실명 / 이메일 / 디바이스 정보를 포함하지 않습니다.
- sessionId 는 발급일 또는 최근 활동일로부터 180일 후 자동 만료됩니다 (TTL).
- 사용자는 언제든 `POST /api/v1/sessions/rotate` 로 sessionId 를 회전 (기존 데이터 owner 단절) 할 수 있습니다.
- v0.4 회원가입 시 익명 sessionId 의 좋아요 / 북마크 / 음역대를 회원 계정으로 이전할 수 있으며, 이 이전에는 사용자의 명시적 동의가 필요합니다 (`docs/features/anonymous-to-account-conversion.md`).
