## v1 본문 (핵심 5 조)

### 제4조 (서비스의 제공 및 변경)

1. 사업자는 다음 각 호의 서비스를 제공합니다.
   - 사용자의 음역대 / 분위기 / 연령대 등 컨텍스트 기반 곡 추천
   - 곡 메타데이터 (제목 / 아티스트 / 장르 / 음역대 / 노래방 곡 번호 등) 검색·조회
   - 사용자 단위 좋아요 / 북마크 / 추천 history 보관 (sessionId 단위 또는 회원 단위)
   - 그 외 사업자가 추가로 정해 공지하는 서비스
2. 본 서비스는 **가사 / 음원 / 미리듣기 음원** 을 직접 제공하지 않으며, 필요 시 외부 영상 서비스 (YouTube 등) 의 정상 embed 만 표시합니다.
3. 사업자는 운영상·기술상의 필요에 따라 제공 서비스의 전부 또는 일부를 변경할 수 있으며, 사전에 사이트 또는 서비스 안에 공지합니다.
4. 서비스 제공 / 변경 / 중단은 무상 (PoC 단계) 기본을 전제합니다. 유상 전환 시 별도 약관 개정 및 동의 절차를 거칩니다.

### 제5조 (회원가입 및 회원 자격)

> v0.2-v0.3 (익명 sessionId 단계) = 본 조 비적용. v0.4 회원화 이후 적용.

1. **익명 이용**: 본 서비스는 v0.4 이전 단계에서 회원가입 없이 sessionId (비식별 무작위 식별자) 단위로 이용할 수 있으며, sessionId 는 일정 기간 (현 정책 180일) 보관 후 자동 만료됩니다 (`docs/decisions/0013-sessionid-ttl-rotation.md`).
2. **회원가입**: v0.4 이후 회원가입을 신청한 사람은 다음 요건을 충족해야 합니다.
   - 본 약관 + 개인정보처리방침에 동의
   - 만 14세 이상 (개인정보보호법 제22조의2)
   - 카카오 / 구글 OAuth 또는 이메일 인증을 통한 신원 확인
3. 사업자는 다음 각 호의 경우 회원가입을 거부하거나 사후 자격을 박탈할 수 있습니다.
   - 타인의 명의로 신청
   - 본 약관 또는 관련 법령 위반 이력
   - 그 외 사업자가 합리적으로 부적합하다고 판단한 경우
4. **익명 → 회원 머지**: 익명 sessionId 에 누적된 좋아요 / 북마크 / 음역대 등은 회원가입 시 본인 식별 동의를 거쳐 회원 계정으로 이전됩니다 (`docs/features/anonymous-to-account-conversion.md`).

### 제7조 (회원의 의무)

1. 사용자 (익명 / 회원 무관) 는 다음 행위를 해서는 안 됩니다.
   - 타인의 sessionId / 계정 도용
   - 자동화 도구로 서비스에 부하를 일으키거나 데이터를 무단 수집 (scraping) 하는 행위
   - 본 서비스가 제공하는 곡 메타데이터를 **사업자 별도 동의 없이** 상업적 목적으로 재배포 / 재가공
   - 음란·폭력·차별·명예훼손·저작권 침해·범죄 등 위법한 콘텐츠를 사용자 기여 채널 (예: 곡 정보 제보) 로 등록
   - 본 서비스의 정상 운영을 방해하는 일체의 행위
2. 사용자는 본인의 음역대 / 좋아요 / 북마크 등 데이터가 비식별 sessionId 단위로 보관됨을 이해하며, 본인이 sessionId 회전 (`POST /api/v1/sessions/rotate`) 또는 삭제 endpoint 를 통해 본인 데이터 처리정지 / 삭제를 행사할 수 있음을 인지합니다.
3. 본 서비스에 표시되는 외부 영상 (YouTube embed 등) 은 해당 외부 서비스의 약관이 별도로 적용되며, 사용자는 외부 서비스 약관을 함께 준수해야 합니다.

### 제12조 (책임 제한)

1. 사업자는 천재지변·전쟁·정전·통신회선 장애 등 사업자가 통제할 수 없는 사유로 서비스를 제공할 수 없는 경우 책임을 지지 않습니다.
2. 사업자는 본 서비스가 제공하는 곡 메타데이터 / 추천 결과의 **정확성·완전성·최신성을 보장하지 않으며**, 다음 사항은 사용자가 자율 판단해야 합니다.
   - 추천 곡이 본인의 실제 음역·취향과 일치하는지
   - 곡 정보가 노래방 / 음원 서비스 등 외부 출처의 최신 정보와 일치하는지
   - 외부 영상 (YouTube embed 등) 의 가용성 / 광고 / 외부 서비스 정책 변경
3. 본 서비스는 가사 / 음원 / 노래방 곡 번호 정확도 등에 대한 보증을 제공하지 않습니다.
4. 사업자는 사용자가 본 서비스를 통해 얻은 정보 / 추천 결과를 통해 발생한 직접·간접·결과적 손해에 대해, 법령이 허용하는 최대 범위 안에서 책임을 지지 않습니다. (단, 사업자의 고의 또는 중과실로 발생한 손해는 제외)
5. 사업자는 사용자 사이 또는 사용자와 제 3자 사이에서 본 서비스를 통해 발생한 분쟁에 개입할 의무가 없으며, 이로 인한 손해를 배상할 책임이 없습니다.

### 제13조 (분쟁 해결 및 준거법·관할)

1. 본 약관 및 본 서비스 이용과 관련한 분쟁은 **대한민국 법령** 에 따라 해석·적용합니다.
2. 사업자와 사용자 사이 분쟁이 발생한 경우 우선 협의로 해결하며, 협의가 이루어지지 않을 경우 민사소송법상 관할 법원에 소를 제기할 수 있습니다.
3. 사용자는 「소비자기본법」 등 관련 법령에 따라 한국소비자원·소비자분쟁조정위원회 등에 분쟁 조정을 신청할 수 있습니다.
